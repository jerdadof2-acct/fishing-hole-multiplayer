# Starfall Lagoon — Location Design Brief

**Status:** Planned (finale destination after Congo River)  
**Display name:** Starfall Lagoon  
**Internal id (saves):** still keyed as CrazyCatch Cove / `chapter_14_crazycatch` until a migration pass

## Overview

Starfall Lagoon is the forgotten tropical lagoon where Halley’s Comet struck in 1607 — the place where the Starfish of Eternity was born, where pirates once hid treasure, and where Halley’s father found wonders he later shared only as “stories.”

Halley discovers this history **in play** (Congo journal → lagoon arrival). The prologue never dumps it.

## Mood

Warm turquoise water with a soft celestial glow. Ancient pirate wreckage. Coral-covered docks. Schools of tiny glowing fish like moving stars. Wonder, recognition, homecoming.

## Signature creatures (from father’s stories)

| Creature | Notes |
| --- | --- |
| Pirate Bannerfish | Ribbon-like fins with tiny comet crystals; guides schools through reefs |
| Butterfly Grouper | Broad translucent fins that scatter light |
| Glass Puffer | Nearly transparent; crystalline spines |
| Moonstripe Wrasse | Marked with every lunar phase; current phase glows |
| Treasurekeeper Octopus | Collects coins, pearls, and shining objects from wrecks |
| Tiny starfish schools | Faint comet-glow points of light throughout the lagoon |

## Story beats

1. Narrow cliff passage → lagoon reveal  
2. Creatures gather around medallion + Starfish  
3. Halley realizes father’s stories were memories  
4. Starfish returns to the reef; Halley releases it  
5. Epilogue narration — greatest treasure was every lesson together
